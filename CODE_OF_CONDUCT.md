# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
By participating you agree to uphold it.

## Reporting

Report unacceptable behaviour privately through this repository's **Security** tab
(**Report a vulnerability**), noting that it concerns conduct. Maintainers will review and
respond, and will keep the reporter's identity confidential.
