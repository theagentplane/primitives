## [0.1.0] - 2026-10-12

First release. Schema version `0.1`. Everything below is new, so every entry is **compatible**; there
is nothing to migrate from. Pre-1.0: pin the exact minor (`agentplane-primitives==0.1.*`).

### Added
- **Entities:** `Trace` (labels are strings, no status of its own), `Span` (`parent_envelope_id`
  links it to the caller) and `Envelope` with identity fields at the top level and nested
  `envelope_status`, `input`, `output` and `metadata`; `attempt` and `links` (`retry_of`).
- **Kinds:** a closed `Kind` enum (`llm`, `tool`). `tool` input and output carry `raw` and an
  optional `error`; `llm` input and output carry the canonical fields, `raw`, content blocks
  (`text`, `tool_call`, `reasoning`, `refusal`), `finish_reason` and the fixed cost fields
  `provider`, `model`, `model_source` and `usage` (five exclusive, additive token buckets).
- **Enums:** `Kind`, `State`, `Status`, `LinkType`, `FinishReason`, `ModelSource`, `MessageRole`.
  A new member of any of them is a schema change.
- **Ids:** `TraceId` (32 hex), `SpanId` and `EnvelopeId` (16 hex), lowercase, never all zero, with
  random generators.
- **`traceparent` carrier:** `TraceContext`, `parse_traceparent()` (strict, never raises:
  anything malformed gives `None`) and `format_traceparent()`. `to_event` and `from_event` are
  reserved names, documented and not implemented.
- **Metadata rules:** lowercase dot-separated keys, the reserved `chronicle.` prefix, string-valued
  trace labels, and the well-known label keys `session_id`, `message_id` and `user_id`.
- **Schemas:** one committed JSON Schema file per stored entity (`Trace.json`, `Span.json`,
  `Envelope.json`), generated by `python scripts/generate_schemas.py`; a test fails when they
  drift from the models.
- **Versioning:** `schema_version` `"0.1"` on every persisted payload; unknown fields are ignored
  on read.
- **Repository:** `src` layout, typed package (`py.typed`), CI, release workflow, dependency
  updates, contribution and security docs, and ADRs 0001 to 0005 in `docs/adr/`.

**Not in this package:** HTTP request and response wrappers. The control plane owns them and
reuses these entities as bodies ([ADR 0003](docs/adr/0003-api-models-live-in-control-plane.md)).
